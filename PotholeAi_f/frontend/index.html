About

Model Information

Everything you need to know about the classifier behind PotholeAI.

🧠

Transfer Learning

MobileNetV2 pretrained on ImageNet is fine-tuned for road surface classification, achieving robust generalisation even with a small training set.

📦

Dataset

Images sourced from the Kaggle dataset virenbr11/pothole-and-plain-road-images-images, split into train, validation and test sets.

⚙️

Preprocessing

Images are resized to 224×224, pixel values normalised to [0, 1], and augmented during training to improve robustness.

⚠️

Limitations

  • Performance may degrade in extreme lighting conditions.
  • Binary only – does not assess pothole severity or size.
  • Trained on ~730 images; more data would improve accuracy.
  • May not generalise to regions not in the training distribution.
🔌

Activate Live Predictions

To enable real ML predictions, export your trained Keras model and place it in the model/ folder:

# In your Kaggle notebook / training script:
model.save("pothole_model.h5")

# Then place the file at:
PotholeAi/model/pothole_model.h5

# Restart the server:
python app.py
The server auto-detects the model file on startup. No code changes required.
