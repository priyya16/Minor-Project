## 🛣️ Pothole and Plain Road Classification

### 📌 Project Overview

This project focuses on classifying road images into two categories: **Pothole** and **Plain Road** using deep learning and transfer learning techniques.

The objective is to help identify pothole-affected roads from images and explore how computer vision can support road condition monitoring.

### 🎯 Objectives

- Classify road images into Pothole and Plain Road categories.
- Apply transfer learning using pretrained convolutional neural networks.
- Evaluate model performance using classification metrics.
- Explore model predictions and visual explanations.

### 🧠 Models Explored

- MobileNetV2
- ResNet50
- EfficientNetB0

### 🛠️ Technologies Used

- Python
- Jupyter Notebook
- TensorFlow / Keras
- NumPy
- OpenCV
- Scikit-learn
- Matplotlib
- Grad-CAM for model visualization

### 📂 Project Files

| File | Description |
|---|---|
| `pothole_classification.ipynb` | Notebook containing the classification workflow, model experiments, and evaluation |

### 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/priyya16/Minor-Project.git
   ```

2. Open `pothole_classification.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
3. Install the required Python libraries if they are not already available.
4. Configure the dataset path according to your environment.
5. Run the notebook cells in sequence.

**Note:** The dataset is not included in this repository. Configure access to the dataset before running the notebook.

### 📊 Evaluation

The notebook explores model training and evaluation for binary road-image classification. Refer to the notebook for the actual metrics, comparisons, and experimental results.
